# React Lab

Interactive React lessons built with React, TypeScript, Vite, TanStack Router, Tailwind CSS, and shadcn/ui. Each lab combines a working example with concise explanations and code samples.

## Start working

Use Node 24 LTS and npm 11. With [nvm](https://github.com/nvm-sh/nvm):

```bash
nvm install
nvm use
npm ci
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:5173`). `.nvmrc` selects Node 24; `package.json` declares supported runtime versions. No environment variables or backend services are required for the labs.

In VS Code, install **Biome** and **Tailwind CSS IntelliSense**. Shared workspace settings enable Biome formatting and safe fixes on save. Select **TypeScript: Select TypeScript Version → Use Workspace Version** from the command palette. This project uses Biome rather than ESLint or Prettier.

## Commands

| Command             | Purpose                                                          |
| ------------------- | ---------------------------------------------------------------- |
| `npm run dev`       | Start Vite with hot reload and route generation                  |
| `npm run lint`      | Check formatting, lint rules, and imports without changing files |
| `npm run lint:fix`  | Apply safe lint/import fixes and formatting                      |
| `npm run format`    | Format files without applying lint fixes                         |
| `npm run typecheck` | Type-check application, config, and tests                        |
| `npm test`          | Run behavior tests with Node's built-in runner                   |
| `npm run build`     | Type-check and generate the production site in `dist/`           |
| `npm run preview`   | Serve the production build locally after building                |
| `npm run check`     | Run lint, tests, and the production build                        |

## Project map

- `src/routes/_dashboard/`: TanStack file routes; keep route files thin.
- `src/features/{section}/{lab}/`: lab pages, local components, and lesson content in `*.data.ts` files.
- `src/content/labs.ts`: shared lab catalog and card artwork.
- `src/components/shared/`: reusable lab cards, topics, and breadcrumbs.
- `src/components/ui/`: shared shadcn/ui primitives.
- `src/hooks/` and `src/lib/`: shared hooks and utilities.
- `tests/`: behavior tests for the upload state machine and PKCE helpers.
- `src/routeTree.gen.ts`: generated by TanStack Router; never edit manually.

## Continue development

1. Create a focused branch, for example `git switch -c codex/my-lab`.
2. Read [AGENTS.md](AGENTS.md) and use a neighboring lab as the structural reference.
3. Add the feature folder, thin route, lab catalog entry, and section listing. Keep static copy and code samples in the lab's data file.
4. Run the dev server to generate routes. Check the actual interaction, keyboard access, and mobile layout.
5. Add focused tests for changed logic, then run `npm run check`. Review and commit any generated route changes with the lab.

The existing tests run TypeScript directly on Node without a test framework. Use relative `.ts` imports in tests; native type stripping does not support JSX or the Vite `@/` alias. The build also checks test types. Introduce browser/component testing when a change needs it rather than adding dependencies for simple pure-logic tests.

CI installs from the lockfile, runs `npm run check`, and verifies the generated route tree is current. Dependabot is configured for weekly npm and GitHub Actions updates; it becomes active when this configuration reaches the default branch and the repository permits it.

## Dependency maintenance

```bash
npm outdated
npm audit
```

Update related packages in small groups, inspect migration notes, and rerun `npm run check` plus affected browser interactions. Keep React/React DOM and their types compatible, update the TanStack router packages together, and keep Tailwind with its Vite integration compatible. Major versions need a separate migration review. Do not blindly apply `npm audit fix --force`; npm may propose unwanted downgrades.

Use `npm audit --omit=dev` to inspect production dependencies separately. Review each finding's dependency path and available fixes before changing versions; audit counts alone do not establish whether the application is exposed.

Commit `package.json` and `package-lock.json` together. Biome is pinned exactly; update its schema in `biome.json` when upgrading. The shadcn package is a development dependency used for component generation and its build-time Tailwind stylesheet. Updating the CLI does not automatically update copied components in `src/components/ui/`.

## Web vitals

`src/main.tsx` currently reports metrics to the browser console. `sendToAnalytics` is an optional helper; to use it, configure `VITE_WEB_VITALS_URL` in `.env.local` and pass `sendToAnalytics` to `reportWebVitals`. Vite exposes `VITE_*` values to the browser, so never put secrets there. The helper skips sending when no endpoint is configured.

## Version decisions

TypeScript 6, `@hookform/resolvers` 5, and web-vitals 5 remain on their current major versions. Upgrade these through dedicated migrations so compiler, form-validation, and metrics changes can be checked independently. React Compiler is not enabled.
